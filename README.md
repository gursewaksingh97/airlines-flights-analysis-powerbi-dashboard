# ✈️ Airlines Flights Analysis | Power BI Dashboard Project

An end-to-end Data Analytics project focused on airline operations, ticket pricing behavior, route analysis, travel duration trends, and revenue performance using Power BI.

This project demonstrates the complete analytics workflow from raw dataset preparation and data cleaning to KPI development, dashboard design, and business insight generation.

---

## 📌 Project Overview

The airline industry generates large volumes of travel and pricing data daily. This project analyzes airline travel patterns, route popularity, pricing behavior, and operational performance to uncover meaningful business insights.

### Objectives

- Analyze airline ticket pricing trends
- Identify high-performing airlines
- Evaluate route popularity
- Understand travel duration patterns
- Generate business insights using interactive dashboards

# 💡 Business Insights

### Revenue Insights

- Jet Airways generated the highest revenue.
- Total airline revenue exceeded ₹97 Million.
- Premium cabin classes contributed significantly to revenue generation.

### Pricing Insights

- Business Class tickets recorded the highest average ticket prices.
- Ticket prices varied substantially across routes and travel durations.
- Route selection had a strong influence on fare distribution.

### Route Insights

- DEL → BOM → COK was the most frequently used route.
- Delhi served as the primary departure hub.
- Cochin emerged as the most common destination.

### Operational Insights

- Average travel duration remained close to 11 hours.
- Peak travel activity was concentrated around specific time windows.
